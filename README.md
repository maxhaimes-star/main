# main

My first GitHub repository, set up with Claude Code.

## How this works

- **Repository**: a project folder that lives on GitHub and keeps the full history of every change.
- **Commit**: a saved snapshot of your files, with a short message describing what changed.
- **Branch**: a separate line of work. Changes are made on a branch, then merged into the main one.
- **Pull request (PR)**: a request to merge a branch, where you can review the changes first.

## Working with Claude

Ask Claude in plain language, e.g. "make a website", "add a to-do app", "write a Python script that...".
Claude writes the code, commits it, and pushes it to this repository.
